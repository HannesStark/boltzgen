# Example directory index

Use this index to find an example folder. Read the folder's YAML files with the [design specification reference](README.md), and keep relative structure paths valid when copying an example. File paths in a specification are resolved relative to its YAML file.

Before generation, use `boltzgen check path/to/design.yaml --output checked/` to parse the specification and write `checked/design.cif` for inspection. The output contains design and binding annotations; select B-factor coloring in your viewer. These annotations are input settings, not model confidence. See the [indexing notes](../README.md#how-to-make-a-design-specification-yaml) before selecting residues, particularly for PDB files with unresolved sequence positions.
